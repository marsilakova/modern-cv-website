# Modern CV-webbplats (Modern CV Website)

En stilren, modern och responsiv personlig CV-webbplats skapad för att presentera mina färdigheter, min utbildning, mina projekt och mina kontaktuppgifter.

## 1. Planering & Design
• Mål: Att bygga ett tydligt och lättillgängligt digitalt CV som fungerar smidigt på både dator och mobil.
• Layoutstruktur: Jag valde en fast sidomeny (sidebar) för datorskärmar för enkel navigering mellan sektioner, som automatiskt omvandlas till en kompakt toppmeny på mobila enheter.
• Färgpalett & Typografi: Jag använde ett ljust tema med hög kontrast för god läsbarhet, kombinerat med ett valbart mörkt läge (Dark Mode) för bättre användarupplevelse.

## 2. Huvudfunktioner
• Header & Introduktion: Visar profilbild, namn, yrkesroll samt snabbknappar för projekt och nedladdning av CV.
• Grundläggande sektioner: Innehåller tydliga avsnitt för Om mig (About Me), Färdigheter (Skills), Utbildning (Education), Projekt (Projects) och Kontakt (Contact).
• Responsiv design: Anpassar sig sömlöst till dator, surfplatta och mobiltelefon med hjälp av CSS Flexbox och Grid.
• Mörkt / Ljust läge (Dark / Light Mode): Interaktiv temaväxlare byggd med JavaScript.
• Ladda ner CV: Inbyggd funktion för att skriva ut eller spara sidan som PDF via knappen Download CV.
* **SEO-optimering:** Optimerad med semantisk HTML5, meta-taggar (`description`, `keywords`) och Open Graph för bättre synlighet i sökmotorer och vid delning på LinkedIn.


## 3. Använda teknologier
• HTML5: Semantisk struktur och tillgänglig kod.
• CSS3: CSS-variabler, Flexbox, CSS Grid, hover-effekter och media queries.
• JavaScript (Vanilla JS): DOM-hantering för temaväxling och aktivt menyval.
• Font Awesome: Vektorikoner för navigering och färdighetskort.

## 4. Testning & Validering
• Enhetstestning: Webbplatsens mobilanpassning har testats i webbläsarens utvecklarverktyg (DevTools) för olika skärmstorlekar.
• Funktionskontroll: Smidig rullning (smooth scroll), växling mellan mörkt/ljust tema samt utskriftslayout har kontrollerats.

## 5. Så här kör du projektet lokalt
1. Klona eller ladda ner detta repository.
2. Öppna projektmappen i Visual Studio Code.
3. Öppna index.html i din webbläsare eller starta sidan med tillägget Live Server eller Live Preview.
